Самопроверка расчётов
Набор правил, уже проверенных вручную: ступени переработок, ночная смена, обед, разрыв, погрузка, снимок ставок, частичные выплаты, многодневные проекты. Прогоняется на собственных тестовых данных — твои проекты не трогает.
Режим
«Работа» — настоящие проекты с сегодняшней датой. «Демо» — песочница с примерами, время в ней остановлено на июле. Сейвы раздельные и друг друга не трогают. При первом входе в «Работу» проекты начинаются с чистого листа, а справочники — команда, ренталы, ставки, правила чтения — переезжают с собой. Важно: у Safari, значка на экране и браузера внутри приложения Claude хранилища РАЗНЫЕ. Заходи всегда одним и тем же способом — иначе увидишь «пустое» приложение, хотя данные целы в другом входе.
Данные приложения
Всё хранится на самом устройстве, без сервера. Чтобы перенести данные на другой телефон или компьютер — выгрузи файл здесь и загрузи его там.

Перенос между входами
У значка на экране, Safari и браузера внутри Claude — разные хранилища. Перенос в два тапа: здесь «Скопировать данные», в другом входе — «Вставить данные». Файл — то же самое, но через «Файлы»: заодно остаётся запасная копия.

Вставить данные

Облако

Общая база для всех устройств — приватный репозиторий на GitHub. Каждое сохранение ложится туда отдельной версией, поэтому вернуть данные за любой прошлый день можно даже после того, как что-то испорчено. Ключ доступа остаётся на этом устройстве и в облако не уезжает.
Где взять ключ
github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Доступ — только к этому репозиторию, право Contents: Read and write. Ключ показывается один раз, скопируй его сразу.

История версий

Выбери дату, чтобы вернуть данные к ней. Нынешняя версия не пропадёт — она тоже останется в списке.

Проверь часы смены и погрузки по каждому юниту — фактическая смета считается по ним. Если перед сменой добирал оборудование, загрузи файлы этих ренталов.

Загрузить прайс

Самый надёжный способ — открыть присланный файл, выделить таблицу, скопировать и вставить сюда: тогда переносится ровно то, что в нём написано. Файл xlsx можно выбрать прямо здесь.
Файл кривой, PDF или фото? Разбери его в чате с Claude по подписке: приложи файл, вставь наш запрос — получишь таблицу EZ-СМЕТА, которую приложение примет без единого вопроса.
